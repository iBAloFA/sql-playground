# SQL Playground

A beautiful, safe, browser-based SQL editor (like phpMyAdmin but modern & fast)

Live demo → https://sql-playground.streamlit.app (after you deploy)

Features
- Connect to SQLite or PostgreSQL
- Run any SELECT query
- Pretty table output with sorting & export
- Safe: only SELECT allowed (no DROP/DELETE)
- One-click deploy on Streamlit Community Cloud

Perfect portfolio project for backend, data analyst & full-stack roles.
